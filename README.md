A RESTful API authentication scheme that combines AES encryption, SHA hashing, salting, and random key generation to issue a single unique key per client — strengthening web application security at the auth layer.
**Stack:** Spring Boot, Postman
[→ View repository](https://github.com/leelendrareddygogula/KeyBasedWebAuthentication)
