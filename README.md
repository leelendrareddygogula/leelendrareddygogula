## Featured Projects

### Key-Based Web Authentication
<strong>Stack:</strong> Spring Boot &middot; Spring Data JPA &middot; MySQL &middot; AES Encryption &middot; SHA Hashing &middot; Salting &middot; Postman

Final-year capstone where I designed and built the entire backend of a RESTful authentication service. Instead of storing raw credentials, the system runs them through a four-stage pipeline - AES encryption, SHA hashing, salting, and random string generation - to issue one unique key per client that handles all subsequent authentication. I owned the architecture, the implementation, Postman edge-case testing, and led the team through delivery.

<a href="https://github.com/leelendrareddygogula/KeyBasedWebAuthentication" target="_blank" rel="noopener noreferrer">View repository &rarr;</a>

### Interior Designer Project
<strong>Stack:</strong> Spring Boot &middot; Spring MVC &middot; Spring Security &middot; JSP &middot; JSTL &middot; MySQL &middot; Google Forms API &middot; Heroku &middot; CI/CD

A revenue-generating web platform built to a real interior-design firm's requirements. The designer can create and revise client quotations with material photos, generate installment bills tracking paid and outstanding balances, and showcase past work. Customer feedback flows in through the Google Forms API and renders as visual charts. I built the full backend and handled deployment; it ran in production for nine months with zero downtime and sub-5ms latency.

<a href="https://github.com/leelendrareddygogula/InteriorDesignerProject" target="_blank" rel="noopener noreferrer">View repository &rarr;</a>

### Cloud AI Photo Platform
<strong>Stack:</strong> Flask &middot; Python &middot; REST API &middot; Google Generative AI &middot; Google Cloud Storage &middot; Cloud Run &middot; GitHub CI/CD

A Pinterest-style photo app where users upload an image and Google's Generative AI automatically produces a title and caption for it. Images and their generated metadata are stored in Google Cloud Storage and surfaced on a gallery home page, where any picture opens with its AI-written details. I exposed the service through four REST endpoints and deployed it on Cloud Run via GitHub CI/CD, splitting traffic 50/50 across two versions.

<a href="https://github.com/leelendrareddygogula/photo-sharing-application" target="_blank" rel="noopener noreferrer">View repository &rarr;</a>

### URL Shortener
<strong>Stack:</strong> Spring Boot &middot; Java &middot; REST API &middot; MySQL &middot; JSP &middot; JSTL

A solo-built URL shortening service in the style of Bitly or TinyURL. It accepts a long URL, generates a compact unique short code, persists the mapping, and redirects visitors to the original destination on lookup. I designed the REST endpoints, the data model, and the lightweight JSP front end end to end. It's a focused study in clean API design, reliable persistence, and efficient key generation and retrieval.

<a href="https://github.com/leelendrareddygogula/URLShortener" target="_blank" rel="noopener noreferrer">View repository &rarr;</a>
